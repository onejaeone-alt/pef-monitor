# IB레이더 AI 운영 1단계

이번 변경은 원문 분석 경로(`/api/signals?mode=research`)의 실행 기록과 배포 전 회귀 평가를 추가한다. 추천 배점이나 취재 범위를 바꾸지 않는다. 별도 유료 서비스나 데이터베이스는 필요하지 않다.

## 운영 기록

Vercel Runtime Logs에서 `ib_radar_ai_ops`를 검색한다. 로컬에서는 `RADAR_OPS_LOG=1`로 활성화할 수 있다.

- `stage=request`: 요청마다 처리 시간, 결과 상태, 원문 확보 수, 검색 실패 여부, 사실·기사 방향 수를 기록한다. 캐시 사용은 `hit`, 실행 중 요청 공유는 `shared`, 새 분석은 `miss`다.
- `stage=model`: 실제 모델 호출마다 성공·오류, 토큰 사용량과 처리 시간을 기록한다. 생성 이후 근거 검증에서 탈락해도 토큰은 기록한다. 토큰을 반환받기 전 실패한 호출은 사용량을 알 수 없어 null이다.
- `trace_id`: 새 분석의 요청과 모델 호출을 연결한다. 캐시를 반환한 요청은 새로운 모델 호출을 만들지 않는다. `shared` 요청의 모델 호출은 최초 요청의 trace에만 존재한다.
- `pipeline_version`, `model`, 프롬프트·출력 스키마 SHA-256, 배포 커밋을 기록한다. 커밋 환경변수가 없으면 null이며 추정하지 않는다. 프롬프트나 스키마가 바뀌면 캐시 키도 바뀐다.
- 원문, 취재 주제, URL, API 키, 모델 입력·출력 전문은 로그에 남기지 않는다.

집계 시 요청 오류율은 request 이벤트만, 토큰은 model 이벤트만 센다. sources_only와 error_code를 함께 확인해 원문 부족·모델 연결 오류를 구분한다. 토큰은 비용의 기초 자료이며 금액을 의미하지 않는다. 요금표를 반영한 비용 계산은 구현하지 않았다.

로그 보존 기간은 Vercel 설정에 따른다. 장기 저장, 자동 알림, 운영 대시보드는 아직 없다. 로깅 실패는 서비스 응답을 중단하지 않는다.

## 배포 전 평가

`npm run eval:ai`는 고정 날짜·예시 입력으로 추천, 검색 후보 선택, 근거 검증을 평가하고 `.ai-ops/evaluation.json`에 사례별 결과와 코드 해시를 남긴다. 17개 필수 사례를 모두 통과해야 종료 코드 0을 반환한다. `vercel-build` 끝에서 이 명령을 실행하므로 실패한 버전은 빌드가 실패한다.

이는 오프라인 회귀 평가다. 실시간 LLM을 호출하거나 기사 품질·정확도·채택률을 측정하지 않는다. 프롬프트를 바꿨다는 이유만으로 생성 품질이 검증된 것은 아니다. 실제 추천의 채택·기각·수정 이유를 기자가 기록한 평가 자료와 별도 생성 평가가 다음 단계에 필요하다. 사용자의 평가 없이 자동 학습하거나 배점을 자동 변경하지 않는다.

평가 기준은 `evals/editorial-cases.json`에서 관리한다. 외부 기사 원문을 포함하지 않으며 취재 기준 검토를 위한 예시다. 오류가 발견되면 재현 사례를 추가하고 기존 버전과 변경 버전을 같은 자료로 비교한다. 평가가 실패했다고 합격선을 낮추는 방식으로 해결하지 않는다.

## 변경과 복구

1. Git 브랜치에서 프롬프트·추천 규칙을 수정한다.
2. `npm test`, `npm run eval:ai`, `npm run vercel-build`를 실행한다.
3. 기존·신규 결과의 차이를 검토하고, 실제 생성 문장 품질은 별도 표본으로 확인한다.
4. 배포 후 해당 커밋의 request 오류와 원문 확보 수, model 사용량을 확인한다.
5. 문제 발생 시 Vercel의 이전 정상 배포로 되돌리거나 해당 코드 변경을 git revert 후 재배포한다. 자동 롤백은 구현하지 않았다.

## RAG 범위

현재 원문 분석은 관련 공개 자료 검색 → 원문 확보 → 모델 입력 → 근거 검사로 이어진다. 드라이브 자료는 `lib/drive-dossier-data.json`의 정리된 자료를 읽는 경로가 있다. 이 구현만으로 벡터DB·임베딩을 사용한다고 설명할 수 없다. WeKnora 도입, 지식 그래프 구축, 드라이브의 실시간 동기화는 이번 변경에 포함하지 않는다.
