## 포함·제외

- 출자사업 **설명회**는 참석 가능한 행사로 포함한다. 출자 접수·운용사 선정 결과 자체는 행사로 만들지 않는다.
- IR, 투자밋업, 데모데이, 딜데이, 네트워킹, 교류회, 설명회, 발표회도 행사 후보로 수집한다.
- 국회·금융위는 자본시장·PEF·VC·기업금융·구조조정·상법·기업지배구조·대체투자·핀테크 등 취재 분야 관련 일정만 포함한다.
- 신청·접수·등록·기업선정 마감일이나 게시일을 행사 날짜로 대체하지 않는다. 본문 연도와 제목 연도가 충돌하면 임의 수정하지 않는다.
- 행사일·장소가 확인되어도 기자 출입·참석 자격이 확인된 것은 아니다. 참가 신청 링크와 원문을 제공한다.

## 깊이·재확인·한계

- 성장금융은 세 게시판을 각각 최대 3페이지 확인한다. 다른 공지 게시판도 실제 페이지 링크가 있으면 추가 2페이지를 확인한다.
- 최근 180일 게시물을 후보로 삼고, KVCA는 회당 최대 48건, 다른 공식 게시판은 최대 12건을 상세 확인한다. 미래 날짜가 제목에 있는 안내·미확인 안내를 먼저 확인하고, 확인 시각을 저장해 다음 수집에서 나머지를 순환 확인한다.
- PDF·HWPX 첨부는 본문에서 날짜를 찾지 못했을 때 최대 2개 확인한다. 이미지 OCR와 옛 HWP 바이너리 해독은 지원하지 않는다.
- 원문 접근 실패·날짜 미확정 후보는 별도 목록에 남긴다. 게시판별 부분 실패와 순차 확인 잔여 건수를 표시한다. 소스 오류 때 기존 일정을 보존한다.
- 공개 검색은 보완 경로이며 검색에 잡히지 않는 비공개 초청장·메일은 수집하지 못한다. 산업은행·캠코·예탁원의 직접 게시판 연결을 완료했다고 표시하지 않는다.
- 최초 깊이 제한 이후에도 모든 과거 페이지를 완주하는 크롤러는 아니다. 공개 목록에서 빠진 오래된 미래 행사, 이미지 전용 행사, 접근이 제한된 원문은 누락 가능성이 있다.
- 금융연구원과 산업은행 대표 홈페이지는 이번 조사에서 안정적인 직접 행사 목록을 확보하지 못했다. 작동하는 수집처로 가장하지 않는다.
