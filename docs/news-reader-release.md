# 뉴스 읽기 개편 · 2026-09-08

기존 뉴스 수집·취재파일·다른 탭을 유지한다. 뉴스 페이지의 읽기 화면만 교체하며 원문·정본 원장·기존 개인 기록을 삭제하지 않는다.

## 적용 범위

- 새로 볼 뉴스 / 추적 중 / 전체 뉴스. 가입·복지·동음이의어와 애매한 보도는 선별 검토에서 확인한다. 선별은 제목 기반 규칙이며 원문 전체 이해 또는 완전한 누락 방지를 보장하지 않는다.
- 읽음은 사용자가 직접 누를 때만 남긴다. 페이지·상세·원문을 열어도 읽음 처리하지 않는다. 일괄 처리는 현재 표시한 기사만 대상으로 한다. 직전 변경을 되돌릴 수 있다.
- 보관함은 조회 기간과 분리한다. URL·제목·매체·발행일 등 공개 기사 표시용 참조만 브라우저에 보관하며 본문 보존·새 사실 정본을 만들지 않는다.
- 추적은 기존 개체 ID 또는 사용자가 정한 AND 검색어를 쓴다. 제목 일치를 동일 사건·새 사실이라고 표시하지 않는다. 현재 수집 결과에서만 찾으며 별도의 상시 수집 작업을 만들지 않는다.
- 다른 탭에서 돌아와 새 보도가 있으면 적용 버튼을 눌러 목록을 바꾼다. 수동 기간 선택·새로고침은 다시 조회한다. 제목·발행시각만 달라진 경우도 비교 전 상태로 알린다.
- ib-news-desk-v1을 읽어 기존 보관·분류를 이어받되 원본 키는 삭제하지 않는다. 새 기록은 ib-news-reader-v2에 저장한다. 링크만 남은 기존 보관은 원문에서 확인하도록 표시한다.

## 미적용

로그인·계정별 DB 저장·기기 간 동기화는 포함하지 않는다. 인증 토큰과 개인 기록을 받는 서버 엔드포인트도 배포하지 않는다. Supabase 인증·DB 설정과 실제 계정 간 접근 격리를 확인한 뒤 별도 구현해야 한다. 현재 같은 기기의 같은 브라우저 프로필을 공유하면 기록이 보인다. 기존 취재 메모 탭이 로그인으로 보호된다고 표시하지 않는다.

기사 본문에서 추가 금액·반론·새 조건을 추출하는 비교 기능도 아직 적용하지 않는다. 화면에는 본문 비교 전임을 표시한다.

## 검증 범위

새 코어·기본 통합 48개를 로컬에서 실행했다. Chromium의 메모리 DOM에서 신규 UI·코어의 11개 동작을 검사했다. 이 DOM 검사에는 수집 API·분류·저장소 테스트 어댑터를 사용했으므로 운영 브라우저 전체 검증을 대신하지 않는다. 빌드에서 실제 분류 모듈과 통합 멱등성 검사 및 기존 새로고침·분류·공개 취재 테스트를 함께 실행한다. 계정 기능 모의 프로토타입은 배포 대상이 아니며 완료로 간주하지 않는다.
