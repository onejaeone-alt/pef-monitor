# DART 취재 신호 게이트

DART 원문을 삭제하거나 수집을 중단하지 않는다. 이 게이트는 IB 취재 레이더 화면에 어떤 공시를 기본 노출할지 정하는 표시 기준이다.

## 기본 원칙

첫 질문은 `무엇이 달라졌는가`다. 제목에 금융 단어가 있다는 이유만으로 먼저 확인 목록에 올리지 않는다. 실제 돈·지배력·위험·거래 조건의 변화 가능성이 있는 공시를 남긴다.

## 먼저 확인

- 경영권 변경 계약, 공개매수, 실제 최대주주 변경
- 타법인 지분 취득·처분, 영업양수도, 합병·분할
- 유상증자, 감자, CB·BW·EB 및 상환·소각
- 담보·보증·차입 가운데 상장사 또는 취재대상과 직접 연결된 건
- 회생·워크아웃·연체·횡령·배임 등 거래·회수에 영향을 주는 위험
- 위 유형의 정정·철회·조건 변경

## 기본 화면에서 제외

- 공모펀드·퇴직연금 등 집합투자증권 투자설명서·신고서·발행실적보고서
- 임원·주요주주 특정증권 소유상황보고서
- 대량보유상황보고서(약식)
- 단순 `최대주주등소유주식변동신고서`는 경영권 변경으로 간주하지 않고 후속 참고로 둔다
- 감시대상과 무관한 비상장 계열사의 반복적인 특수관계인 자금대여·차입·유상증자 참여
- 스팩 해산사유 발생은 먼저 확인에서 제외하고 참고 목록에 둔다

대량보유상황보고서(일반), 스팩 해산 등은 필요할 수 있으므로 관련 공시 전체에서 확인 가능하게 유지한다. 기사 가치 점수는 만들지 않는다.
