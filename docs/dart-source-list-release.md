# DART 원문 목록 정리 — 2026-09-08

사용자 판단: ‘변화·질문’의 미리 작성한 질문과 자료 종류 안내는 실제 추가 조사 결과가 아니다. 공시 원문 조회와 취재 판단을 분리한다.

## 이번 변경

- DART의 별도 변화·질문 화면, 쟁점 카드, 분석 집계, 일괄 읽기 버튼을 제거한다. 원문 목록과 간단한 검색·구분·기간·정정 필터만 보인다.
- ‘내용 확인’을 누르면 선택한 공시 바로 아래에서 정정 전후 값, 기재 사유, 출처 위치와 읽지 못한 항목을 볼 수 있다. 최초 진입·새로고침·필터 변경으로 원문 분석을 실행하지 않는다.
- 제목에서 고른 질문, 실제로 찾지 않은 ‘대조할 자료’, 자동 가설은 DART 표시·복사·신규 취재 연결에 사용하지 않는다. 기존 정본 ID와 공시 접수번호를 연결한다.
- 기존 원문·추출 결과·취재 메모·판단 이력은 일괄 삭제하지 않는다. 기존 프로젝트의 가설과 메모를 덮어쓰지 않는다. 과거 분류 모듈과 검증 사례는 보존하되 화면에서 더는 불러오지 않는다.
- 공통 헤더·로그인·뉴스·AI 발견·기사작성기 및 원문 추출 서버는 변경하지 않는다. 신규 유료 모델 호출, 비공개 메모 업로드, 정본 쓰기는 없다.

## 구현하지 않은 것

이번 수정은 자동 사전조사의 성능 개선을 주장하지 않는다. 과거 공시의 동일 거래 식별, 관련 보도 본문 비교, 새 사실과 반대 근거를 종합하는 에이전트는 이 변경에 포함되지 않는다. 그런 실제 추가 조사 없이 일반적인 질문 목록을 ‘취재 결과’로 다시 노출하지 않는다.

## 검증

새 원문 목록 단위 테스트 20개를 로컬에서 통과했다. 오프라인 Chromium에서 가상 fetch·저장소로 최초 분석 0회, 개별 원문 펼치기, 검색·정정필터, 이전 결과 유지, 질문 없는 복사, 390px 레이아웃을 검사했다. 실제 로그인 세션·외부 사이트 이동은 검사하지 않았다. 전체 저장소 검사와 공통 헤더 통합은 배포 빌드에서 확인한다.
