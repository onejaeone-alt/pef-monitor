# 기사 추천 규칙

추천 단위는 취재를 시작할 수 있는 기사 방향이다. 미보도 사실, 마켓인 본문 확보, 추가 취재 완료를 추천의 필수 조건으로 삼지 않는다. 수집한 사실을 비교하거나 설명할 질문과 근거 링크는 반드시 있어야 한다.

## 자료와 확인 범위

- 국내 뉴스·외신은 최근 14일을 요청한다. 실제 수집 범위와 실패 여부는 화면에 표시한다.
- 이 브라우저에 수집한 뉴스·공고는 최대 90일, 종류별 1,200건까지 보관해 다음 비교에 사용한다. 처음 접속했을 때 90일 자료가 모두 있는 것은 아니다.
- 출자공고, 취재 일정, 근거 항목이 있는 DART 원문 검토 결과도 사용한다.
- 제목, 요약, 본문 확보 여부를 구분한다. 제목에 없는 거래 조건·원인·참여자를 만들어 채우지 않는다.
- 기업명과 기관 약칭, 거래 대상, 행동, 날짜를 기준으로 묶는다. 같은 거래의 여러 보도를 여러 투자 사례로 세지 않는다.

## 기사 방향 생성

| 유형 | 비교하거나 설명할 대상 |
|---|---|
| LP 출자·선정 | 출자 분야, 자금의 쓰임, GP 참여 조건 |
| LP 비교 | 별개 출자사업의 투자 분야와 선정 기준 |
| GP 투자·회수 전략 | 같은 운용사의 서로 다른 투자·회수·펀드 조성 |
| 업종별 투자 비교 | 같은 업종의 별개 거래와 투자 대상 |
| 회수 방식 비교 | 비교 가능한 기업의 매각·상장·지분 회수 방식 |
| 거래 변화·해설 | 경영권 이전과 자본 확충, 거래 중단, 분리 매각, 인수 심사 |
| 자금 조달 해설 | 공개된 조달 목적과 만기·상환 계획 |
| 예정된 발표 | 7일 안의 실제 일정과 공개된 의제 |

같은 기업이라는 이유로 별개 거래를 조건 변경으로 해석하지 않는다. 검토·추진·가능성·계약·완료를 구분한다. 농지·주택 단순 매각, 주가 전망, 가정형 인수 기사는 기업 거래 추천에서 제외한다. 일반적인 문서 대조 절차 자체는 기사 방향으로 제시하지 않는다.

## 순위

| 항목 | 배점 | 판단 내용 |
|---|---:|---|
| 기사 구체성 | 30 | 비교 대상, 설명할 질문, 확보한 조건 |
| IB 중요도 | 25 | LP·GP·PEF·M&A·인수금융과의 관계 |
| 시의성 | 20 | 최근 보도·변경과 예정된 일정 |
| 자료 충실도 | 15 | 제목 외 자료, 별개 사례, 공식 자료 |
| 보도 관심도 | 10 | 중복을 제외한 보도 확산 |

현재 자료만으로 독립 취재와 비교 가능한 과거 보도량을 확정할 수 없으므로 관심도는 최대 5점만 사용한다. 수집 실패나 검색 범위 변경을 보도 급증으로 계산하지 않는다. 점수는 추천 순위이며 사실의 확실성을 뜻하지 않는다. 같은 출처 묶음의 중복 추천을 줄이고 기사 유형과 분야의 다양성을 보조 기준으로 쓴다. 처음에는 최대 5건을 보여주며 더 있는 방향은 펼쳐 볼 수 있다.

## AI 분석과 화면

규칙으로 만든 기사 방향을 먼저 표시한다. 관련 본문을 읽은 AI 분석은 별도로 보완한다. AI가 다른 방향을 제안해도 사용자가 선택한 원래 방향을 덮어쓰지 않는다. 마켓인 본문을 읽지 못한 경우 기보도 확인의 한계로 표시하며 미보도라고 주장하지 않는다.

카드에는 가제, 어떤 기사인지, 지금 볼 이유, 근거 뉴스를 표시한다. 점수와 추천 규칙은 펼쳐 본다. 추가 취재 질문은 기사 상세에 짧게 둔다. AI 분석 실패로 규칙 추천을 지우지 않으며, 자료 수집 실패로 이전 추천을 유지할 때는 원래 기준 시각을 표시한다.

## 검증

`tests/discovery-recommendations.test.js`는 사례 중복·추천 생성·범위 판정 등을 검증한다. `tests/recommendation-tab.test.js`는 AI 지연·실패에도 추천이 열리는지, 출처와 확인 범위, 선택한 기사 방향 저장, 분야 필터와 이전 결과 유지를 검증한다. 배포 전 `npm run vercel-build`로 사이트의 기존 필수 검사를 함께 실행한다.
