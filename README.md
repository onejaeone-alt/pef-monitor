# IB 취재 레이더 · PEF Monitor

PEF Monitor는 **뉴스·DART·모태펀드·관계 자료를 무료 공개소스 중심으로 모아 보는 기자용 취재 콘솔**입니다.

핵심 원칙은 간단합니다.

> 수집과 정리는 코드·공개 API가 한다.  
> 기사 판단과 문장 생성은 자동으로 유료 AI를 돌리지 않는다.  
> 필요한 건만 `ChatGPT용 취재패키지`로 만들어 사용자가 ChatGPT Pro에서 직접 처리한다.

## 현재 화면

### 1. 뉴스

첫 화면입니다. 특정 하우스 몇 곳만 보는 감시목록 방식보다 넓게 아래 IB 주제를 모니터링합니다.

- M&A·PEF
- VC·스타트업
- LP·정책자금
- IB·회사채·자금조달
- 펀드레이징·자산운용
- 국민연금·공제회·산업은행·SI·FI

PEF Monitor와 Article Engine은 서로 다른 웹앱으로 운영합니다. PEF Monitor 상단의 `기사 엔진 ↗`을 누르면 독립된 [원재연 기사 엔진](https://article-engine-wjy-onejess.vercel.app/)이 새 창에서 열립니다.

매체별로 나누지 않고 주제와 시간순으로 봅니다. 기사 가치 점수는 매기지 않습니다.

### 2. DART 공시

DART 공시는 기사 후보가 아니라 원재료입니다.

- 경영권·최대주주 변동
- 지분 취득·처분
- 합병·분할·사업재편
- 유상증자·CB·메자닌
- 담보·보증·차입
- 회생·법적 위험
- 펀드·조합 변동

등 취재에 활용할 만한 사건형 공시를 넓게 모읍니다. 화면에는 `왜 모니터링하는 공시인지`만 표시합니다.

### 3. 모태펀드

KVIC 출자사업을 사업 단위로 봅니다.

`출자계획 → 접수 → 서류심사 → 최종선정 → 실제 결성펀드`

선정 발표와 실제 결성을 구분해 보존합니다. 장기적으로 GP별 지원·서류통과·최종선정·실제결성 이력을 연결하는 것이 목표입니다.

### 4. 관계·취재파일

최근 자료에서 직접 확인되는 관계만 보여줍니다.

- 투자
- 인수·매각
- 펀드 결성
- GP·LP
- 인사 이동

같은 기사에 이름이 함께 나왔다는 이유만으로 관계를 만들지 않습니다. 관계 화면은 최근 자료를 우선하며, 저장된 단서를 먼저 사용해 페이지를 열 때마다 외부 뉴스 사이트를 다시 긁지 않습니다.

`취재파일 바로가기`에는 최근 14일 안에 새 이슈가 있는 대상만 최대 6곳까지 표시합니다. 나머지 드라이브 기업카드는 운용사·기업명이나 카드 안의 이슈를 검색해 같은 상세 취재파일로 열 수 있습니다. 관계에서 회사나 인물을 누르면 드라이브 기업카드, 직접 관계, 관련 거래, 최근 관련 뉴스를 한 상세창에 묶어 보여줍니다.

### 5. 기사판단기

**준비 중**입니다.

DART 한 건이나 뉴스 한 건으로 자동 기사 후보를 만들지 않습니다. 나중에 같은 기업·GP·펀드·거래에 대해 서로 다른 출처가 겹칠 때만 판단 대기열에 올리는 구조로 연결할 예정입니다.

### 6. 기사작성기

PEF Monitor 안에서 유료 생성 모델을 호출하지 않습니다.

입력:

- `무슨 일이 생겼나요?`
- 기사 형식: 스트레이트 / 인터뷰 / 심층취재 / 칼럼 / 르포
- 선택 사항: 취재 메모

PEF Monitor가 무료로 관련 자료를 모아 다음을 만듭니다.

- 관련 DART
- 공식 공고
- 보도자료
- 국내외 보도
- 최근 관계·거래
- 추가 취재 질문
- 원재연 기사 스타일 지시문

결과 화면에서 다음 기능을 사용합니다.

- `ChatGPT용 자료 복사`
- `TXT 저장`
- `복사 후 ChatGPT 열기`

복사된 패키지를 사용자가 현재 구독 중인 ChatGPT에 붙여 넣어 기사를 작성합니다.

## 비용 원칙

PEF Monitor 코드에는 OpenAI 유료 모델 호출을 넣지 않습니다.

현재 사용 소스:

- DART Open API
- KVIC Open API
- Google News RSS 및 공개 뉴스 피드
- GDELT 등 공개 소스
- Supabase 저장 DB
- Vercel 서버 함수

각 서비스의 무료 제공량·정책은 바뀔 수 있으므로 무료 티어 한도는 별도로 확인해야 합니다. 그러나 **PEF Monitor 자체에서 OpenAI 토큰 사용료가 자동 발생하는 구조는 제거했습니다.**

## 효율화 원칙

1. 새 자료 수집은 공개 API·RSS·HTML 파싱으로 처리합니다.
2. 중복 제거·날짜 정렬·키워드 분류·기업명 매칭은 일반 코드로 처리합니다.
3. 관계 페이지는 저장된 최근 단서를 먼저 사용합니다.
4. KVIC 과거 자료는 크론으로 조금씩 백필합니다.
5. 같은 원문을 매번 다시 읽거나 같은 자료를 반복 저장하지 않습니다.
6. 기사 생성은 PEF Monitor 서버가 하지 않습니다.

## 자동 수집

Vercel Cron에서는 현재 KVIC 자료만 자동 백필·갱신합니다.

- 과거 KVIC 출자사업 백필
- 최신 KVIC 출자사업 갱신

`오늘 기사 후보`, `주간 기사 후보` 같은 자동 AI 브리핑 크론은 사용하지 않습니다.

## 주요 파일

- `index.html` — 뉴스 홈
- `dart.html` — DART 공시 원재료
- `motae.html` — 모태펀드 출자사업 트래커
- `relations.html` — 최근 관계·취재파일
- `judgment.html` — 기사판단기 준비 화면
- `writer.html` — 무료 취재패키지 생성·복사 화면
- `api/news.js` — IB 주제 뉴스 수집
- `api/dart-feed.js` — DART 사건형 공시 피드
- `api/kvic.js` — KVIC 실제 결성펀드 API
- `api/kvic-backfill.js` — KVIC 출자사업 공지·첨부 수집
- `api/ontology.js` — 최근 단서 관계 변환
- `api/entity.js` — 대상별 취재파일
- `api/entity.js?action=search` — 드라이브 기업카드 검색
- `api/writer.js` — 자료 대조와 ChatGPT용 취재패키지 생성
- `lib/chatgpt-package.js` — 원재연 기사 스타일을 포함한 복사용 패키지 생성
- `lib/writer-principles.js` — 기사 형식·검증 원칙
- `lib/ontology.js` — 관계·거래 그래프 생성
- `lib/drive-dossiers.js` — 드라이브 기업카드 색인·최신 이슈 선별
- `lib/supabase.js` — 수집 자료 저장·조회

## Vercel 환경변수

필수 또는 현재 사용 중인 값만 둡니다.

```text
DART_API_KEY=OpenDART 인증키
KVIC_API_KEY=한국벤처투자 Open API 인증키
SUPABASE_URL=https://<project-ref>.supabase.co
SUPABASE_SECRET_KEY=sb_secret_...

# 선택 사항: 없으면 공개 뉴스 피드 중심으로 동작
NAVER_CLIENT_ID=네이버_애플리케이션_클라이언트_ID
NAVER_CLIENT_SECRET=네이버_애플리케이션_시크릿
```

`OPENAI_API_KEY`와 `ARTICLE_MODEL`은 PEF Monitor 동작에 필요하지 않습니다. Vercel에 남아 있어도 현재 코드에서는 사용하지 않습니다.
