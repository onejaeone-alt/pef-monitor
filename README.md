# IB 취재 레이더

DART 공시를 많이 보여주는 대신, IB 기자가 오늘 확인할 기사 후보를 고르는 모니터입니다.

## 화면

- **오늘 기사 후보**: 기사감 75점 이상 가운데 상위 5건
- **취재 필요**: 기사감 55~74점과 5건을 넘은 후순위 후보
- **참고·보관**: 정기보고서와 단서가 약한 공시
- **내 감시목록**: 지정한 회사·운용사가 포착되면 화면 점수에 15점 가산

공시마다 다음 정보를 표시합니다.

- 새로 포착된 사건과 현재 단계
- 같은 회사·사건의 이전 공시
- 왜 기사감인지와 다음 확인 사항
- 전화할 대상과 맞춤 확인 질문
- 스트레이트·후속·기획 기사 방향
- 기사감 점수와 항목별 산정 근거

`원문 숫자·문장 추출`을 누르면 필요한 공시에 한해 DART 원문 압축파일을 읽습니다. 금액·지분·금리·만기와 거래 관련 문장을 우선 추립니다. 표 구조가 풀리며 문장이 어색할 수 있으므로 기사 작성 전 원문과 대조해야 합니다.

## 잡음 제거 원칙

- `파트너스`, `인베스트`, `사모` 같은 일반 명칭 하나만으로 관련 공시로 판정하지 않습니다.
- 회사·제출자의 PEF·VC 관련성과 이번 사건의 IB 관련성을 따로 평가합니다.
- 단순 감사보고서는 확인된 하우스가 아니면 목록에서 제외합니다.
- PEF 명칭이 없어도 경영권, 인수·매각, 합병·분할, 자금조달, 회생처럼 중요한 사건은 남깁니다.

기사감 점수는 새 변화 25점, 거래 중요도 20점, 단계 진전 15점, 취재처 관련성 15점, 이례성·마찰 15점, 공시 근거 10점을 기준으로 계산합니다. 공시 제목만으로 알 수 없는 거래금액과 보유 목적을 임의로 추정하지 않습니다.

## 구조

- `index.html` — 기자용 취재 데스크 화면
- `lib/story-engine.js` — 사건 분류, 잡음 제거, 기사감 점수, 취재 질문
- `api/enriched.js` — DART 수집, Supabase 누적 이력, 회사별 1년 이력, 원문 추출
- `api/dart.js` — 상세 API 장애 시 사용하는 가벼운 폴백
- `lib/supabase.js` — 공시와 기사 후보 저장, 과거 공시 조회
- `supabase/schema.sql` — 공시·기사 후보·기업·거래·관계·근거 사실 스키마
- `tests/story-engine.test.js` — 핵심 분류 규칙 회귀 테스트

## Vercel 환경변수

```text
DART_API_KEY=OpenDART 인증키
SUPABASE_URL=https://<project-ref>.supabase.co
SUPABASE_SECRET_KEY=sb_secret_...
```

키는 Vercel 서버 함수에서만 사용합니다. 브라우저 코드와 API 응답에 키를 넣지 않습니다.

## Supabase

Supabase Dashboard의 SQL Editor에서 `supabase/schema.sql`을 실행합니다. 기존에 초기 스키마를 실행했다면 같은 파일을 다시 실행해도 됩니다. `if not exists`를 사용해 기존 공시를 지우지 않고 다음 구조만 추가합니다.

- `disclosures`: DART 공시 원재료와 전체 분석 결과
- `article_candidates`: 점수, 전회 대비, 취재 질문, 기사 방향
- `entities`: 기업, PEF·VC 운용사, SPC, 금융기관
- `deals`: 하나의 M&A·투자·자금조달 거래
- `deal_events`: 거래별 공시·뉴스 타임라인
- `entity_relations`: 매도자·매수자·GP·LP·주선사 관계
- `source_documents`, `fact_claims`: 출처와 검증 가능한 사실

확장 스키마를 아직 실행하지 않아도 화면과 기존 `disclosures` 누적 저장은 작동합니다. 확장 테이블이 확인되면 API가 `article_candidates` 저장을 자동으로 시작합니다.

## 테스트

```bash
npm test
npm run check
```

현재 테스트는 일반 `파트너스` 감사보고서와 공모펀드 투자설명서 제외, PEF 경영권 공시 우선 후보 판정, 일반 회생 공시 제외, 감시기업 자금조달 보존, 정정공시 비교 안내, 과거 공시 연결을 확인합니다.
